## How To Use

Install via your preferred package manager. We recommend using [BUN](https://bun.sh) for the best experience and installing globally.

```bash
# BUN
$ bun install -g please-readme

# NPM
$ npm install -g please-readme

# PNPM
$ pnpm install -g please-readme

# YARN
$ yarn global add please-readme
```
